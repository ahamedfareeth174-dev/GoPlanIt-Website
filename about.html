About GoPlanIt

A student planner for assignments, reminders, notes, and study flow.

Made by Ahamed Fareeth. Connect on LinkedIn.

What it does

GoPlanIt keeps school tasks, calendar dates, study notes, reminders, and priority planning in one browser-based workspace.

  • Add assignments, exams, reminders, and tasks from the calendar.
  • Review today's focus and upcoming work from the dashboard.
  • Save notes, create study summaries, and generate practice quizzes.
  • Search tasks and notes after logging in.

Data and backups

This demo stores account and planner data locally in your browser. Use dashboard backups before clearing browser data or moving devices.

  • Export backup downloads your planner data as a JSON file.
  • Import backup restores saved data for the current logged-in account.
  • Passwords are hashed when the browser supports the app database.

How to start

Create an account, try the demo planner, or log in and open the dashboard.
